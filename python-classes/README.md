# Python - Classes and Objects

This directory contains implementation files for Python Classes and Objects.

## Tasks

* **0. My first square**: An empty class `Square` that defines a square.
* **1. Square with a size**: Class `Square` with private instance attribute `size` and instantiation.
* **2. Size validation**: Class `Square` with private instance attribute `size` and type/value validation.
* **3. Area of a square**: Class `Square` with `area` method.
* **4. Access and update private attribute**: Class `Square` with getter and setter properties for `size`.
* **5. Printing a square**: Class `Square` with a `my_print` method to print the square using `#`.
* **6. Coordinates of a square**: Class `Square` with a `position` attribute and coordinates handling.
