# Python - More Classes and Objects

This directory contains implementation files for Python Classes and Objects focusing on Rectangle class.

## Tasks

* **0. Simple rectangle**: An empty class `Rectangle` that defines a rectangle.
* **1. Real definition of a rectangle**: Class `Rectangle` with private instance attributes `width` and `height`, along with properties and validation.
* **2. Area and Perimeter**: Class `Rectangle` with `area` and `perimeter` methods.
* **3. String representation**: Added `__str__` method to print the rectangle with `#`.
* **4. Eval is magic**: Added `__repr__` method to recreate a new instance using `eval()`.
* **5. Detect instance deletion**: Added `__del__` method printing a deletion message.
* **6. How many instances**: Tracking number of instances using class attribute.
* **7. Change representation**: Using a customizable class attribute `print_symbol` for string representation.
* **8. Compare rectangles**: Static method `bigger_or_equal` to compare area of two rectangles.
* **9. A square is a rectangle**: Class method `square` returning a new Rectangle instance with equal width and height.
