# SQL - Introduction

This directory contains implementation files for basic SQL tasks using MySQL, covering:
- Creating and removing databases.
- Creating tables and inserting rows.
- Select queries with various filters, sorting, grouping, aggregates.

## Tasks

* **0. List databases**: Script listing all databases.
* **1. Create a database**: Script creating `hbtn_0c_0` if it doesn't exist.
* **2. Delete a database**: Script deleting `hbtn_0c_0` if it exists.
* **3. List tables**: Script listing tables of a database.
* **4. First table**: Script creating `first_table`.
* **5. Full description**: Script displaying full description of `first_table`.
* **6. List all in table**: Script selecting all rows from `first_table`.
* **7. First add**: Script inserting a record into `first_table`.
* **8. Count 89**: Script counting records with `id = 89`.
* **9. Full creation**: Script creating `second_table` and inserting initial records.
* **10. List by best**: Script listing records of `second_table` ordered by score descending.
* **11. Select the best**: Script listing records with `score >= 10`.
* **12. Cheating is bad**: Script updating Bob's score to 10.
* **13. Score too low**: Script removing records with `score <= 5`.
* **14. Average**: Script computing average score.
* **15. Number by score**: Script grouping and counting by score, sorted descending.
* **16. Say my name**: Script listing records with a non-empty name.
